# LEO Thermal Environment — Week 1

## 1. Reference Orbit

- Reference altitude: 400 km
- Orbit environment: Low Earth Orbit (LEO)

## 2. Thermal Environment Parameters

| Parameter | Value | Unit | Status |
|---|---:|---|---|
| Solar flux | 1361 | W/m² | Project reference |
| Earth albedo | 0.30 | — | Project reference |
| Earth infrared radiation | 237 | W/m² | Project reference |

## 3. Steady-State Simulation Condition

For the Week 1 steady-state thermal simulation:

- Solar flux = 1361 W/m²
- Eclipse = OFF
- Initial temperature = 20 °C

The eclipse condition is excluded from the initial steady-state run.

The following parameters will be defined in the material-properties
stage:

- Solar absorptivity
- Infrared emissivity
- Thermal conductivity
- Density
- Specific heat
