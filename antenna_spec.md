# GNSS Helix Antenna Specification — Week 1

## 1. Antenna Overview

The antenna selected for the project is an axial-mode helical antenna
for GNSS L1 operation.

- Antenna type: Axial-mode Helix
- GNSS band: L1
- Target frequency: 1.575 GHz
- Polarization: RHCP

## 2. Published Geometrical Parameters

| Parameter | Value | Unit | Status |
|---|---:|---|---|

| Helix circumference | 212 | mm | Published |
| Turn spacing / pitch | 42 | mm | Published |
| Total antenna length | 193 | mm | Published |

## 5. Notes

Published parameters and modeling assumptions are intentionally kept
separate. Assumed values must not be interpreted as measured or
manufacturer-specified values.
